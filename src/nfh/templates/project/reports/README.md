# Reports

Everything here is written by the agents, for you to read: research findings,
plans, feedback you asked to have saved, and the reading list. You never need to
edit these files. To change something, say so in the chat (for example
"shortlist C3" or "that objection is fine") and the agent records it.

- `plans/`: plans from the assistant
- `research/`: the assistant's cited findings
- `feedback/`: feedback the Sparring partner saved because you asked it to
- `reading-list.md`: works proposed for reading, and your decisions on them
