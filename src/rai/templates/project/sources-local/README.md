# Local sources

Your own notes, transcripts or interviews that aren't in Zotero. Supported:
.pdf .epub .html .md .txt. For each file you can add a sidecar named
`<file>.yaml`, e.g. `interview-04.md.yaml`:

    title: Interview with a delivery rider
    authors: [Your Name]
    year: 2026
    cite_key: interview04

Then run `rai ingest --local` (or `rai refresh`).
